Right-click.
Open with Claude.

Adds an "Open with Claude" entry to the right-click menu. Right-click a folder, or empty space inside one, and Claude Code opens in that folder in a new window.

Download v1.0.0

Prefer double-click? Get open-with-claude-windows-v1.0.0.zip and double-click install.bat inside.

Heads up: the scripts are unsigned, so Windows will show a SmartScreen warning. Read install.bat first, then choose "Run anyway". Linux and macOS users: the same scripts, best effort.

Which install first.

On Windows 11, start with the Classic menu: it is the tested path and works on Windows 10 too. Pick the top-level entry only if you want the entry in the main menu and already have Visual Studio Build Tools with the C++ workload.

Classic menu start here

Registry entry under HKCU. Shows under "Show more options" on Windows 11, directly on Windows 10.

install.bat

Top-level menu optional

Sparse MSIX package with a small COM DLL. The entry appears in the main right-click menu on Windows 11.

modern\build-modern.bat

If the entry does not appear after installing, sign out and back in (or restart Explorer); the classic entry registers per user. On Windows 11, look under "Show more options".

Where it runs.

Windows is the tested path. Linux and macOS are best effort, and the release zips contain the same scripts.

Trust, but verify.

Unsigned scripts, said plainly, plus everything you need to check them yourself.

Read the script first

install.bat is small and readable: it registers the menu entry under HKCU and, if you have the build tools, builds the top-level entry. install.bat, linux/install.sh, macos/install.sh.

Uninstall is one step away

uninstall.bat, sh linux/uninstall.sh, or sh macos/uninstall.sh removes the entry for the current user. No admin needed to install or to remove.
